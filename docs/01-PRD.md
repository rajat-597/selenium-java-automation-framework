# Selenium Java Automation Framework — PRD

## Purpose
Build a realistic, scalable Java Selenium automation framework that helps testers create, execute, maintain, debug, and report automated tests consistently.

The framework is primarily a Selenium UI automation framework. API and database capabilities are supporting capabilities for realistic scenarios, not separate full API/DB frameworks.

## Main capabilities
- Selenium Web UI automation
- TestNG
- Chrome, Firefox and Edge
- Controlled parallel execution
- Dynamic and isolated test data
- API support using Rest Assured
- Database support using JDBC
- Screenshots and failure diagnostics
- Logging
- Reporting
- Configuration/environment management
- Configurable retry/failure handling
- CI/CD readiness
- Future option for Selenium Grid/cloud execution

## Learning goal
The project is designed to learn framework design, automation thinking, test selection, failure analysis, debugging, API/DB supporting capabilities, and framework quality.

The number of tests is flexible. We add tests when they teach a useful concept.
